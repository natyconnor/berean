Settled decisions

Decisions locked before implementation

Fixed constraints resolved with the product owner. Treat as non-negotiable.

Decision Resolution
Desktop shell Electron thin shell loads https://berean.nathanconnor.dev (override via BEREAN_DESKTOP_URL for local/dev). Does not bundle the Vite dist/. Web deploys update desktop automatically.
Platform order Mac first (this plan). Windows/Linux only after Mac is proven — not in these PRs.
Distribution Signed + notarized .dmg via GitHub Releases + download link on the website (login footer). No Mac App Store.
Desktop auth Complete Google OAuth inside Electron BrowserWindows on the production origin (same Convex Auth flow as web). True system-browser OAuth cannot share Convex Auth session storage with the shell without a custom token bridge — deferred. Use a persistent session partition so File → New Window shares login.
Offline No offline app data / Bible. Shell shows a local offline error page if the production URL cannot load. Network required for UI.
Deep links Normal https://berean.nathanconnor.dev/… URLs (passages, memory, study, search, settings — whatever the web route already is). Optionally open in the Mac app via Associated Domains + custom scheme berean://. Signed-out deep links keep the path, show login, then continue to that route after auth.
iPad v1 PWA + “Add to Home Screen” guidance. Mouse/keyboard OK. No touch/pen redesign. Capacitor / App Store deferred (no capacitor/ code in this plan).
UI parity Desktop ≈ web. Hide PWA install UI in Electron. Native title bar. Window title “Berean”. Min size 1024×700; default ~1280×800.
Versioning One semver from root package.json. Desktop reports the web app version (already via /version.json on the loaded site). Electron binary version may match package.json at build time.
Accounts Google only. One Convex account everywhere (web + desktop + future iPad).
Tooling Plain Electron + electron-builder (not electron-vite). Reuse existing Vite web app unchanged as the content source.
Marketing / about page Deferred. This plan only adds a Mac download link on the login footer (and GitHub Releases).

Data flow

User launches Mac app → Electron creates a persist:berean window → loads https://berean.nathanconnor.dev (or deep-link path) → existing Vite React SPA + Convex Auth run exactly as in Chrome. Google sign-in completes in-app (popup/child window). Web deploys change Vercel assets; desktop users get the existing /version.json refresh prompt. Share links use https; macOS may hand the URL to Electron via Associated Domains / berean://; main process navigates a window to that path. If signed out, RootRouteComponent shows LoginPage while the router URL stays on the deep link; after auth, AppShell + Outlet render that route. iPad users install via PWA (Add to Home Screen); no separate binary in this plan.

Rules for the agent

Conventions every PR must follow

Workflow

  • One PR at a time, in order. Read files before editing.
  • After code changes run pnpm run agent:check (format → lint → typecheck).
  • Run pnpm test for any PR that adds/edits a *.test.ts.
  • Regenerate Convex types with pnpm run codegen only if Convex files change (this plan should not need Convex changes).
  • Never commit or push unless the orchestrator checkpoint step asks.
  • Do not implement Windows/Linux targets, Capacitor, offline sync, or a marketing homepage unless a PR explicitly lists it.
  • Prefer exact versions (pnpm / save-exact=true) when adding dependencies.

Desktop / web rules

  • Electron: contextIsolation: true, nodeIntegration: false, no remote module.
  • Never load arbitrary URLs — only berean.nathanconnor.dev (or BEREAN_DESKTOP_URL override) and local offline.html.
  • Do not register Electron menu accelerators that collide with Cmd/Ctrl+K, G, ,, J, or Enter.
  • Keep the React app a SPA: no Next.js, no SSR requirement.
  • No any; type the preload bridge and pure helpers.
  • If a public Convex function is touched (should be rare): args + returns, auth, indexes, no Date.now() in queries, await every promise.
  • Static files for AASA/manifest go under public/; ensure vercel.json Content-Type headers where needed.
